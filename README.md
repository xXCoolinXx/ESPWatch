# ESPWatch
ESPWatch for the Arduino <br>

This is a project I made back in 2017. I had the initial goal of creating a fully functioning OS to put on your watch where you could play games and stuff, but I was never able to finish it. I did pick up the project again 2022 and finally in May 2025 and July 2026. I am using a Waveshare ESP32 S3 with a GAC901 LCD display + touch screen.

The watch features an analog clock, a digital clock, a modular app system, a Pong app, a Snake app and a News app.

See the `devenv.nix` for instructions on how to run.
